# Security policy

This repository contains public data and validation tooling. Do not disclose
credentials, private URLs, account identifiers, or active access tokens in an
issue or pull request.

For a vulnerability in repository automation, signing, release distribution, or
the validation tooling, use GitHub's private security advisory flow for this
repository. Do not publish an exploit or secret in a public issue.

Reports about an ordinary tracking parameter that was missed belong in the
**Missed URL cleanup** issue form.
